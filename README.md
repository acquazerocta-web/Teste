# Quiz de Clareza Emocional

Aplicação web estática, pronta para uso em celular e desktop.

## Como usar agora

1. Abra o arquivo `index.html` no navegador.
2. Ou rode um servidor local:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Configurar botão de WhatsApp

No arquivo `app.js`, ajuste:

- `WHATSAPP_NUMBER` com seu número (DDI + DDD + número, sem símbolos)
- `WHATSAPP_MESSAGE` com a mensagem desejada
